# Roadmap

## Desktop application

- [x] Shared core and MVVM layers.
- [x] WPF client for Windows and Avalonia client for macOS/Linux.
- [x] Email, Database, and Calendar studios, MCP runtime, and Live Inspector.
- [x] Draft-preserving editor transitions and confirmations for destructive
  studio actions.
- [x] Verify the .NET store against a database generated by the Electron store.
- [x] Exercise all 22 tools through the .NET MCP client.
- [x] Verify discovery and calls for all 22 tools with the TypeScript MCP SDK.
- [x] Verify MCP Inspector tool discovery and a representative call for each
  studio, with no schema portability warnings.
- [ ] Verify interoperability with additional MCP client hosts.
- [ ] Verify packaged user-data paths on each supported OS before guaranteeing
  in-place reuse of existing databases.
- [ ] Validate the WPF client on Windows and the Avalonia client on macOS and
  Linux; finish accessibility and reduced-motion review.
- [x] Add self-contained release archives for Windows x64, macOS arm64/x64, and
  Linux x64/arm64.
- [x] Package a macOS application bundle in the release archives.
- [ ] Validate published apps on each OS, provide native installers, and
  sign/notarize macOS releases.
- [x] Retire the Electron client, packaging, and JavaScript toolchain; build
  both desktop clients from the root .NET solution.

## Later product work

1. Virtual File Storage mock with traversal-safe paths.
2. Visual custom mock-server and tool builder.
3. Scenario definitions, deterministic assertions, and run comparisons.
4. Additional connectors and optional agent-runner adapters.

Later work should preserve local-first operation, explicit mock boundaries, and
observability of actual tool calls.
